# AI Expense, Linguistic Coach & Cloud Vault - Final App Specification

## 1. Visual Identity & Theme
- **Theme:** AMOLED Black (True Black #000000) for battery efficiency and high contrast.
- **Accents:** Neon Cyans, Purples, and vibrant Gradients for a futuristic, high-tech aesthetic.
- **Design Style:** Ultra-fluid, glassmorphic elements, glowing states, and X-inspired (Twitter) top-tab navigation.

## 2. Core Navigation (Bottom Tab Bar)
- **Home:** Overview of finances (Donut Chart) and Chronological Activity feed.
- **Insights:** Historical spending analytics and AI-powered Trend forecasting.
- **Discover:** AI-curated news feed (For You) and Bookmarked Articles (Saved).
- **Cloud:** Google Drive integration hub with File management and Sync History.
- **AI Coach:** Unified hub for Language correction (Coach) and Vocabulary (LexiAI).

## 3. Key User Flows

### A. Home Hub (Finance)
- **Overview Tab:** Interactive category circle, total balance, and manual budget progress.
- **Activity Tab:** X-style swipeable feed of recent transactions with swipe-to-edit/delete actions.
- **Logging Flow:** Floating '+' button -> AI Scan or Manual Entry -> Advanced Logging (Bank/Card selection) -> Success Animation.

### B. Insights Hub (Analytics)
- **Overview Tab:** Historical spending charts for Today, Yesterday, 7 Days, Month, 6 Months.
- **Trends Tab:** AI-generated forecasts, anomaly detection, and 'Full Breakdown' deep dive.

### C. Discover Hub (News)
- **For You Tab:** Card-based RSS feed with pull-to-refresh.
- **Saved Tab:** Searchable library of bookmarked AI summaries.
- **Article View:** Prominent AI Insights, reading progress bar, and action buttons (Share, Favorite, Read).

### D. Cloud Hub (Storage)
- **Files Tab:** Full-width view of Google Drive contents with 'Upload New' action.
- **History Tab:** Detailed log of activity transmission (Local to Drive, etc.).
- **Upload Flow:** Real-time metrics screen (Progress %, Speed, ETA).

### E. AI Coach Hub (Language)
- **Coach Tab:** Voice/Text grammar correction with context-aware variations (Zoom, Slack, etc.).
- **LexiAI Tab:** Word/Phrase exploration with dictionary definitions and usage examples.
- **Saved Tab:** Searchable personal vocabulary library.

## 4. Global Settings
- **Theme Toggle:** Switch between AMOLED Black and Amoled White.
- **Manual Budget:** Set the hardcoded monthly limit for dashboard calculations.
